# 17 — מפרט מערכת הניהול UPME של גרינטק (כפי שנמצאה בפועל)

**נבדק:** 22.11.2026, מחובר כבעל האתר, **בקריאה בלבד**. נפתחו 53 מסכי תפריט ו־36 מסכי משנה (עריכת מוצר, קטגוריה, ספק, משלוח, קופון, הנחה, סט, משתמש וכו'). לא נשמר אף טופס, לא נלחץ אף כפתור פעולה, ולא נפתח אף קישור מחיקה, שחזור, ייצוא או "התחברות כמשתמש".
**לא נפתח:** "כיבוי האתר" (`system|shutdown_site`). כל ערכי מפתחות, סיסמאות וטוקנים הוסתרו.

מקרא: ✅ אומת בפועל · 🟡 חלקי · ⛔ לא נפתח בכוונה

## 1. מבנה כללי

- **כתובת:** `/admin?am={module}&ac={action}[&id=N][&pam={parent}]`. כל שמירה נעשית ב־AJAX ל־`/admin/adminAjax/{Module}/{action}/[id]`, עם תגובת JSON בפרוטוקול UPME (ראה 06, BR-11).
- **ממשק:** תבנית Metronic (Bootstrap 3). טבלאות DataTables, חלק בטעינה מהשרת (הזמנות, מוצרים, משתמשים).
- **עורך טקסט:** TinyMCE. **מנהל קבצים:** ResponsiveFileManager (`/app_public/js_plugins/filemanager/dialog.php`).
- **סוגי משתמשים** (`user[type]`): ‏0 רגיל · 50 פרימיום · 69 מנהל זוטר · 70 מנהל אתר · 80 ספק (Vendor) · 99 SuperAdmin.
- **קבוצות משתמשים:** קיימת קבוצה 1, "משתמשים שרכשו". הקבוצה משמשת למחיר מוצר לפי קבוצה, מחיר משלוח לפי קבוצה וקופונים לפי קבוצה.

### 3.3 קבצים דיגיטליים — הלב של המכירה הדיגיטלית ✅

| שדה | משמעות |
|---|---|
| `digital_downloads[file]` | הקובץ המלא (RAR). מוצג "קיים קובץ דיגיטלי" |
| `digital_downloads[ref_product][]` | **שימוש בקבצים של מוצרים אחרים** (בחירה מרובה מ־1,228 מוצרים). כך מוצר יכול לתת הורדה של קבצי אלבומים אחרים בלי להעלות אותם שוב |
| `digital_downloads[sample]` | קובץ דוגמית. מוצג "קיים קובץ דוגמית" |
| `digital_downloads[preview_name]` | שם לדוגמית |
| `digital_downloads[physical_price]` | **תוספת מחיר לעותק פיזי**. במוצר 8550: מחיר 50 + תוספת 20 = "רכישת האלבום + הורדה 70 ₪" |
| `digital_downloads[one_button]` + `one_button_title` | **כפתור אחד** במקום שניים, עם כותרת מותאמת ("לרכישת האלבום (הורדה כלולה)") |
| `digital_downloads[only_digital]` | **דיגיטלי בלבד**: כפתור "הורדת האלבום" יחיד |
| `digital_downloads[remove]` | הסרת הקובץ |

**כלל המחיר:** `price` = מחיר הורדה בלבד. `price + physical_price` = פיזי + הורדה.

### 3.4 סטים (מארזים) ✅
- **59 סטים** בדיוק, כמו בדוח הקודם.
- מסך "מוצרים" של סט (`manage_rels`) מציג רשימת מוצרים קיימים, עם כפתור מחיקה לכל רכיב. אין שדה כמות או סדר גלוי, והסדר הוא סדר הרשימה.
  - דוגמה: סט 2614, "שרה זילברברג - בקצב הילדים [מארז]", כולל 4 מוצרים.
- **מארז 8254 אינו סט.** זה מוצר USB רגיל, עם מלאי 1, מחיר 129.90 ויצרן 313, בלי רכיבים.
- **בלקוח:** סט דיגיטלי שנקנה מציג כפתור הורדה לכל רכיב, וגם "הורדת כל הקבצים".
- **שני מנגנונים לרכיבים:** רכיבים מוגדרים גם דרך `ref_product` בקבצים הדיגיטליים, וגם דרך סט. במערכת החדשה שניהם יאוחדו ל־BundleItem.
