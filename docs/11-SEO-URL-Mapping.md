## 3. מאפייני slug ✅

- עברית מלאה, מקודדת UTF-8 ב־URL (`%D7%...`).
- רווח ותווים מיוחדים הופכים למקף; גרשיים נמחקים (`חב"ד` → `חב-ד`).
- נשמרים תווים כמו `·`, `׳`, `ç` (`dvd-français`), ספרות ואנגלית.
- מקף מוביל/סוגר נשמר (`english-dvd-`, `אקפלה-ללא-כלי-נגינה-`).
- כפילות → סיומת `-1`.
- slug של מוצר כולל לפעמים טקסט שיווקי ישן (`youtube-·-מוטי-שטיינמץ-motty-steinmetz-מוטי-שטיינמץ-אמונה-וביטחון`).

## 4. מטא־נתונים

| רכיב | ממצא | סטטוס |
|---|---|---|
| `<title>` | ניתן להגדרה ידנית לכל קטגוריה, ספק ומוצר ("ישי ריבו \| שירים ודיסקים לרכישה \| מחירים נוחים ✔️ לכל כיס", "... \| האלבום לרכישה"). חלק מהכותרות עם אימוג'י | ✅ |
| `meta description` | לכל מוצר, ככל הנראה מתוך התיאור הקצר | ✅ |
| `meta keywords` | קיים בדף הבית | ✅ |
| `link rel=canonical` | קיים בקטגוריות, מוצרים, ספקים, מאמרים ודפי תוכן; חסר בסל, חיפוש והתחברות | ✅ |
| `meta robots` | לא נמצא באף דף שנבדק (גם לא `noindex` בחיפוש) | ✅ |
| Open Graph | ‏`og:type`, ‏`og:title`, ‏`og:image`, ‏`og:url` בדפי מוצר | ✅ |
| JSON-LD | `Product` בדף מוצר. בעיות: reviewCount לא שלם, ‏VAT false, ‏`//` ב־image, ‏brand יחיד כשיש כמה ספקים | ✅ |
| `hreflang` | לא נמצא | ✅ |
| `sitemap.xml` | **404** | ✅ |
| `robots.txt` | 200, מכיל רק `User-agent: *` (ללא Disallow, ללא Sitemap) | ✅ |

## 6. תוכנית מיפוי URL למערכת החדשה

1. **ייצוא מלא של כל ה־URL הקיימים:** 3,882 מוצרים (קיים בסריקה הציבורית; ראה `evidence/public-catalog-id-ranges.txt`) + קטגוריות + ספקים + מאמרים + דפי תוכן. הייצוא המלא עם slug לכל מזהה יופק מהניהול או מהרצה חוזרת של `evidence/storefront-crawl.js`.
2. **כלל ברירת מחדל:** כל URL ישן נשמר כפי שהוא ב־GREENTEC 2.0 (200, לא 301). כך אין אובדן דירוג.
3. **301 רק במקרים אלה:** מוצרים שנמחקו ← קטגוריה ראשית או מוצר חלופי; קטגוריות שאוחדו; תיקון slug פגום (`תוכן-יהודי-יודאיקהספריםותשמישי-קדושה`) — עם 301 מהישן.
4. **תיקון 404 של `/המוצרים-שלנו/*`:** להחליט אם הדפים צריכים לעבוד או להפנות.
5. **`/סרטים-dvd`:** להחליט אם לפתוח קטגוריה ציבורית בכתובת זו או להשאיר רק כקידומת.
6. **עימוד:** לשמר `?page=N`.
7. **פרמטרי סינון:** לשמר את `filter[supplier][id]` ו־`filter[price]` לפחות לקריאה, כדי שקישורים מסוננים שנשמרו ימשיכו לעבוד.
8. **להוסיף:** sitemap.xml, ‏robots.txt עם הפניה ל־sitemap, ו־`noindex` לחיפוש ולדפי מערכת.
9. **מזהים מקודדים:** endpoints חדשים יקבלו גם את הקידוד הישן (BR-02.2) לתקופת מעבר, כדי שעגלות ורשימות משאלות פתוחות לא יישברו.

## 7. בדיקת קבלה ל־SEO

- 100% מה־URL שבסריקה מחזירים 200 במערכת החדשה עם אותו `h1` ואותו canonical.
- 0 שרשראות הפניה (redirect chains) ארוכות מקפיצה אחת.
- `<title>` ו־`meta description` זהים למקור במוצרים, קטגוריות וספקים.
